# Ssemakula Arthur — Cybersecurity Portfolio

A responsive, dark-themed portfolio built with plain HTML, CSS, and JavaScript for **Ssemakula Arthur**, a Cyber Security student at ISBAT University.

## Website contents
- `index.html` — home page, about, skills, selected projects, CV download, learning journal, and contact details
- `styles.css` — responsive visual styling
- `script.js` — mobile navigation and current-year footer
- `assets/Ssemakula_Arthur_CV.pdf` — downloadable CV
- `DEPLOYMENT-GUIDE.md` — step-by-step GitHub Pages setup
- `project-templates/` — reusable project report and profile README templates

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a **public** repository named exactly `ssemakulaarthur23.github.io`.
2. Upload the *contents* of this folder to the repository root (do not upload the parent folder as a nested folder).
3. Confirm that `index.html`, `styles.css`, `script.js`, and the `assets/` folder appear at the top level.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. When the deployment finishes, visit `https://ssemakulaarthur23.github.io`.

Official guide: https://docs.github.com/en/pages/quickstart

## Safety and accuracy checklist
- Only publish work you actually performed and can explain.
- Keep findings sanitized; do not publish credentials, tokens, private IPs, personal data, or sensitive client/target information.
- Test only systems you own or have explicit authorization to assess.
- The skill list describes learning areas and exposure, not a claim of mastery.
- Review the CV PDF before publishing it publicly.
