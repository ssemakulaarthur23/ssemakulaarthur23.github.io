# Ssemakula Arthur — Cybersecurity Portfolio

A responsive, dark technical portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Included
- Responsive hero, about, toolkit, project, journey and contact sections
- Links to the five verified public GitHub project repositories
- LinkedIn, GitHub and email contact links
- CV download at `assets/Ssemakula_Arthur_CV.pdf`
- Mobile navigation and custom SVG favicon

## Publish with GitHub Pages
1. Create or open the public repository `ssemakulaarthur23.github.io`.
2. Upload the **contents** of this folder to the repository root. Keep `index.html` at the root and preserve the `assets` folder.
3. Commit to the `main` branch.
4. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Visit `https://ssemakulaarthur23.github.io` after deployment completes.

## Update links
Edit `index.html` and replace the project URLs or contact details only with verified links. The CV link is relative: `assets/Ssemakula_Arthur_CV.pdf`.

## Safety
Only publish sanitized reports and screenshots. Never expose passwords, tokens, private IP details, client data, or targets tested without authorization.
